# Dev Environment Manager

Dev Environment Manager (DEM) is a modular Bash-based toolkit for preparing Debian Desktop and Debian Server environments.

## Features

- Debian Desktop Profile
- Debian Server Profile
- Development Environment
- Docker Stack
- Database Stack
- Office Installation
- Development Tools
- Repair Utilities
- Backup & Restore
- Health Check

## Requirements

- Debian 13+
- Bash 5+
- sudo
- Internet Connection

## Usage

```bash
./dem.sh doctor
```

```bash
./dem.sh status
```

```bash
./dem.sh install desktop
```

```bash
./dem.sh install server
```
